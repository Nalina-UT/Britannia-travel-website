# Britannia Travel Website ✈️

A responsive travel agency website created using HTML5, CSS3, and JavaScript.

This project was developed as a travel agency website concept to showcase travel destinations, tour packages, services, and travel experiences through a modern and interactive user interface.

## 🌍 Features

- Responsive travel agency website
- Modern and clean user interface
- Travel destination sections
- Tour packages
- Interactive hero slider
- Animated sections
- Travel inspiration gallery
- About the travel agency section
- Customer testimonials
- Travel enquiry/booking section
- Responsive design for desktop, tablet, and mobile
- Font Awesome icons
- Google Fonts integration
- High-quality travel images

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

### Libraries & Resources

- Font Awesome
- Google Fonts
- Unsplash Images

## 📌 Project Purpose

This website was created as a travel agency website project to demonstrate front-end web development skills, including responsive layouts, modern UI design, CSS animations, JavaScript interactions, and user-friendly website structure.
